Метеостанция ESP32-S3 — функционал
Назначение
Домашняя метеостанция: принимает данные с уличного передатчика (ATmega328P + BME280 + nRF24L01), показывает текущую погоду, прогноз, графики и статистику на 
цветном TFT-дисплее. Логирует данные на SD-карту, может отдавать их по Wi-Fi (веб-сервер), синхронизирует время по NTP, обновляется по OTA.

Аппаратная часть
ESP32-S3 — основной контроллер (приёмник).

TFT-дисплей (480×320, TFT_eSPI) — главный экран, меню, графики, статистика.

nRF24L01 (HSPI) — приём пакетов с уличного передатчика.

BME280 (I2C) — температура/влажность/давление в доме.

SCD40 (I2C) — CO₂ в доме.

DS3231 (I2C) — часы реального времени (RTC).

SD-карта (VSPI, отдельные пины) — логирование.

Датчик освещённости (ADC) — авто-подсветка.

Клавиатура (ADC, 5 кнопок: UP/DOWN/LEFT/RIGHT/OK).

Светодиод (GPIO) — индикация.

Уличный передатчик (ATmega328P)
BME280 (питание через GPIO, включается только на время измерения).

nRF24L01 (канал 0x7A, 250KBPS, PA_LOW).

Сон между измерениями (60 сек, LowPower.powerDown).

Bi-color светодиод (красный/зелёный) — индикация штатной работы и ошибок.

Кнопка — вход в отладочный режим (без перепрошивки).

Отладочный режим — не спит, команды в Serial (d, q, r, ?, i, t), логи «шапка / данные / сводка / ошибки».

Основные функции (приёмник)
Главный экран — текущие T/H/P с улицы, T/H/CO₂ дома, прогноз (иконка + текст), тренды (стрелки ↑/↓/→), время/дата, индикаторы SD/WEB/батареи.

Прогноз — три источника: собственный (RF, по давлению/влажности/трендам), Open-Meteo, Яндекс.Погода. Переключение в меню.

Графики — 24 часа / 7 дней / 30 дней, по T/H/P (стрелка вправо).

Статистика — сравнение «вчера в этот час», день / неделя / месяц (стрелка влево).

Меню — подсветка (авто/ручная, калибровка датчика), датчики (калибровки уличных и домашних, высота над морем), время (ручная установка + NTP), тренды (пороги + гистерезис, в EEPROM), Wi-Fi (вкл/выкл, интервал, настройка через портал, API-ключ Яндекса), источник прогноза, «Скачать логи» (веб-сервер), «О системе» (диагностика), OTA.

Логирование на SD — 4 файла:

raw_hourly.csv — сырые данные (раз в 5 мин, очищается в :00);

hourly_YYYY-MM.csv — часовые средние;

daily_YYYY-MM.csv — дневные min/max/avg;

month_YYYY-MM.csv — месячный лог с заголовками дней.

Восстановление при старте (restoreCurrentHour, restoreDailyStats), защита от NaN, блочное чтение с конца.

Веб-сервер — список файлов на SD, скачивание, удаление. Два режима: «с подсказками» (блокирующий, на экране) и «без подсказок» (неблокирующий, AP на главном экране).

OTA — обновление прошивки по Wi-Fi (meteostancija / пароль).

Система логов — logger.h / logger.cpp, уровни ERROR/WARN/INFO/DEBUG, команда d в Serial (вкл/выкл подробные логи), isDataFake (подмена данных для отладки без радио).

Настройки — хранятся в EEPROM (яркость, калибровки, время, тренды, Wi-Fi, координаты, период прогноза, SD-логирование).
